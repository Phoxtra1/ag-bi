# Info Solutions by Amineva Global

Info Discovery is a universal, cross-industry search and paid-report experience. InfoService is a separate professional engagement workflow.

## Info Discovery

- One large search input; customers can enter any information need across industries.
- Lovable Cloud AI performs the discovery and prepares the information behind the scenes.
- The initial screen shows only a short summary and overview.
- The complete document is organized using the five pillars: Discover; Analyze and assess; Verify; Organize and connect; Present the outcome. The seven capabilities are applied within those pillars.
- Customers pay once, per document, to access, print or save the full report. No compulsory subscription.
- Product recommendations are generated by the AI from the meaning of the search, not by hardcoded keyword rules. Amineva Suite is not recommended here; customers access that productivity workspace separately from the Amineva Global homepage. The AI may recommend AgroClimate, Adesua, Inventra, SikaSem or DataLens only when the user's actual information need aligns with that product. If none is relevant, Info Discovery simply delivers the requested information.

## InfoService

InfoService remains a separate request-based professional service across Career and Education, Business Information, Contracts and Commitments, Travel and Relocation, and Info and Report Verification. Staff assess the request, discuss scope, quote, invoice and deliver.

## Lovable Cloud setup

1. Connect this project to Lovable Cloud.
2. Enable Lovable AI for the project so the server-side `LOVABLE_API_KEY` is available to Edge Functions.
3. Apply migrations in order, including `202611180004_private_discovery_reports.sql`.
4. Deploy the `info-discovery` Edge Function.
5. Set server-side secrets `SUPABASE_SERVICE_ROLE_KEY`, and optional `AMINEVA_SUITE_URL` and `AGROCLIMATE_URL`. Never expose private keys in browser variables.
6. Connect Stripe/payment processing separately. The unlock endpoint must only return the private full document after a trusted server-side payment confirmation updates the discovery run to `payment_status = 'paid'`.

Lovable AI calls are made from the Edge Function, not the browser. If Lovable Cloud or Lovable AI is not connected, Info Discovery returns a clear configuration error rather than displaying sample or hardcoded information.
